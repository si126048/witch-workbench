# 0.3.0 中文界面与可靠性更新

本版将继承的剧本、剧情图、角色、素材、演出、诊断、统计、设置、恢复窗口和原生菜单纳入简体中文词表，并使用 Monaco Editor 随附的官方简体中文消息。用户剧本、代码标识、文件名及外部工具日志保留原文。未识别的界面消息回退到英文。

修复工具栏在窗口变窄时按钮被压缩、遮挡而无法点击的问题。中间工具区可横向滚动，按钮和画布切换组保持宽度。项目测试等待初始化与分析完成后才开始操作。

2026-11-06 已验证：

- 中文设置面板、原生菜单和 Monaco 右键菜单可用。
- 1280 与 960 像素视口下，四个画布切换按钮均能真实点击，不使用强制点击。
- 中文端到端检查 3 项通过，运行在隔离 Windows 桌面。
- 中文词表检查不会引入错误占位符；参数保持原文，不再次解释其中的替换符或标签。

原始 0.2.0 团队功能验收记录仍独立保留。本记录不将外部托管平台的权限、真实远端 LFS 配额或成员电脑环境视作已验证。安装包未签名，手动升级；实际分发包与完整门禁结果将在本记录中附列。
