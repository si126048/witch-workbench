# 夜幕工作台 0.2.0 团队启动验收记录

日期：2026-11-05。平台：Windows 11 x64。版本：0.2.0（Windows 文件版本 0.2.0.0）。本版提供未签名安装包，采用手动升级；0.1.0 交付材料保留。

## 交付能力

| 入口 | 行为 | 实际验证 |
|---|---|---|
| 负责人建队 | 初始化独立游戏仓库、配置 origin、保留现有远端、导出成员加入 ZIP，可选附带安装程序 | 真实仓库配置与导出通过；安装包摘要和便携配置字段验证通过 |
| 成员首次加入 | 从加入脚本启动或导入配置、检测 Git/LFS、选择空目录、克隆默认分支、配置该副本的提交身份和 SDK | 真实克隆、第二实例转交、身份写入通过；无凭据时保留错误提示 |
| 日常开工 | 创建个人 Windows 快捷方式，自动 fetch 并打开本地工作副本，失败时离线工作 | 原生 .lnk 创建、独立进程冷启动、自动打开项目通过 |

加入包为数据配置，包含名称、仓库地址、分支和推荐 SDK 版本，不包含密码、令牌、可执行命令或负责人本机项目路径。个人快捷方式另指向本机配置目录中的启动记录。系统 Git 负责认证；首次成员权限、凭据、Git/LFS 安装和 SDK 获取仍由成员完成。

负责人须先在托管平台创建仓库、邀请成员，并完成初次提交与推送。本版没有自动创建 GitHub 组织或替用户配置成员权限；这与既定托管平台管理边界一致。
